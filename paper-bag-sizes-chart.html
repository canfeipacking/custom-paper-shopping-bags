Paper Bag Sizes & Dimensions

Pick the right size and paper weight first time. Our paper bag size chart lists common shopping, gift and grocery dimensions in cm with recommended gsm and best use.

Get a Quote WhatsApp

How to read a bag size

  • Width × Height × Gusset — gusset is the side/bottom depth.
  • Match to the product, not the print area — measure the contents first.
  • Pair size with gsm — bigger bags need heavier paper for the load.
  • Handle type changes usable height — rope adds drop, flat does not.
  • Any bespoke size is available; these are the popular starting points.

Size is the first decision

Get the size wrong and nothing else matters — the bag won't fit the product or will feel flimsy. Start by measuring the tallest, widest and deepest item, add a little room, then choose from the common formats below. Full dimensions and gsm pairings support every style, from rope shopping bags to grocery carriers. Learn how weight scales with size in the materials guide.

Sizing tips that prevent returns

For bottles and jars, size to the outer cap diameter and add a reinforced base (see wine bags). For apparel, prefer a wider gusset so folded garments slide in. For gift sets, consider a square-bottom bag that stands up. If you're between sizes, go one up — an overstuffed bag looks cheap. Ready to spec yours?
